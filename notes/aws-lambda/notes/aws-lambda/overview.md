# AWS Lambda Overview

- To create a Lambda function, you need to follow these steps:
  1. Sign in to the AWS Management Console and navigate to the Lambda service.
  2. Click on "Create function" and choose one of the available options:
     - Author from scratch: Create a new Lambda function from scratch by providing a function name, runtime, and execution role.
     - Use a blueprint: Select a pre-configured blueprint that provides a starting point for your Lambda function, including sample code and event sources.
     - Container image: Create a Lambda function using a container image stored in Amazon ECR (Elastic Container Registry).
     - Browse serverless app repository: Choose a serverless application from the AWS Serverless Application Repository and deploy it as a Lambda function.
  3. Configure the function settings, including the function name, runtime (programming language), and execution role (permissions).
  4. Write or upload your code for the Lambda function.
  5. Set up triggers that will invoke the Lambda function, such as an API Gateway endpoint, S3 bucket event, or CloudWatch event.
  6. Test the Lambda function to ensure it works as expected.

## Example

- We're going to create a simple Lambda function using Author from scratch option, with Python 3.13 as the runtime, and an execution role with basic Lambda permissions:
  1. Sign in to the AWS Management Console and navigate to the Lambda service.
  2. Click on "Create function" and select "Author from scratch", then provide a function name (e.g., "MyFirstLambdaFunction"), choose Python 3.13 as the runtime, and select an existing role or create a new role with basic Lambda permissions.
  3. Click on "Create function" to create the Lambda function.
  4. In the function code editor, write a simple Python function that returns a greeting message:
     ```python
     def lambda_handler(event, context):
         return {
             'statusCode': 200,
             'body': 'Hello from MyFirstLambdaFunction!'
         }
     ```
  5. Click on "Test" to create a test event.
  6. Configure the test event with a name (e.g., "testing") and click on "Test".
     - The Lambda function will execute, and you should see the output in the console, confirming that the function works as expected.
     - Check the logs in Amazon CloudWatch to see the execution details and any output generated by the Lambda function.
     - In the test tab, you can view the response from the Lambda function, which should display the greeting message: "Hello from MyFirstLambdaFunction!"
     - In the monitoring tab, you can view metrics such as invocation count, duration, and error count for the Lambda function.
  7. You can also set up triggers for the Lambda function, such as an API Gateway endpoint, S3 bucket event, or CloudWatch event, to invoke the function in response to specific events.
  8. Delete the Lambda function when you're done testing to avoid incurring charges for unused resources.

## Pricing

- AWS Lambda pricing is based on the number of requests and the duration of code execution.
- You are charged for the number of requests your functions receive and the time your code executes, measured in milliseconds.
- The first 1 million requests per month and 400,000 GB-seconds of compute time per month are free under the AWS Free Tier.
- Beyond the free tier, you are charged based on the number of requests and the duration of code execution, with rates varying by region.
- For the most up-to-date pricing information, refer to the [AWS Lambda Pricing](https://aws.amazon.com/lambda/pricing/) page.
