# AWS Lambda

- AWS Lambda is a serverless compute service that allows you to run code without provisioning or managing servers. It automatically scales your applications by running code in response to events, such as changes in data, shifts in system state, or user actions.
- The main advantages of AWS Lambda is that each lambda is a virtual function that does not require a server to run, and you only pay for the compute time you consume on each invocation, making it cost-effective for many use cases.
- Benefits:
  - Cost-effective: You only pay for the compute time you consume, which has a free tier of 1 million requests and 400,000 GB-seconds of compute time per month.
  - It's integrated with many AWS services, making it easy to build event-driven applications.
  - It's integrated with many programming languages, including Node.js, Python, Java, C#, and Go, allowing developers to use their preferred language for building serverless applications.
  - It's easy to monitor and troubleshoot with built-in logging and monitoring capabilities through Amazon CloudWatch.
- Main integrations:
  - API Gateway: To create RESTful APIs that trigger Lambda functions.
  - Kinesis: To process real-time streaming data with Lambda functions.
  - DynamoDB Streams: To respond to changes in DynamoDB tables with Lambda functions.
  - S3: To trigger Lambda functions in response to events in S3 buckets, such as object creation or deletion.
  - AWS IoT (Internet of Things): To process data from IoT devices and trigger Lambda functions based on events.
  - AWS CloudWatch Events: To schedule Lambda functions to run at specific times or intervals.
  - AWS CloudWatch Logs: To store and analyze logs generated by Lambda functions for troubleshooting and performance optimization.
  - AWS SNS (Simple Notification Service): To send notifications and trigger Lambda functions based on events in SNS topics.
  - AWS Cognito: To authenticate and authorize users for Lambda functions in serverless applications.
